# Disciples Map Quiz

An interactive map quiz about where the twelve disciples, Mark, and Paul ministered, served, and died.

The app includes:

- Clickable country-level map answers
- Country highlighting for correct and incorrect selections
- Score tracking
- Retry, hint, reveal, and next-question controls
- Journey summaries after correct answers
- Country names that appear when they fit on the map
- Antique nautical map styling with illustrated sea creatures
- Responsive layout for phones and desktop screens
